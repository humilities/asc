# HPL 与 HPCG 参数扫描

2026 年 11 月 15 日在同一台 WSL2 Ubuntu 上串行运行。沿用 [基线的环境和程序](../README.md)，以 SHA256 核对两项可执行文件。全程使用单节点、4 个 MPI 进程、每进程 1 个线程，使用 Open MPI 默认绑定。

- HPL 固定 `N=11520`、`P×Q=2×2`，扫描块大小 `NB`。
- HPCG 固定进程和线程数，扫描每个进程的立方网格边长。每次设为 30 秒。这会改变全局问题规模，结果用于比较不同测试负载下的评级。
- 各配置跑两次，第一轮按参数递增，第二轮反序。表中平均值用两次有效成绩计算。

## HPL 结果

单位为 GFLOP/s。10 次运行均通过残差校验。

| NB | 第一轮 | 第二轮 | 平均 |
|---:|---:|---:|---:|
| 128 | 163.07 | 159.02 | 161.05 |
| 192 | 170.19 | 153.71 | 161.95 |
| 256 | 164.52 | 152.93 | 158.73 |
| 320 | 159.96 | 157.87 | 158.92 |
| 384 | 159.22 | 156.03 | 157.63 |

`NB=192` 的平均成绩最高，仅比 `NB=128` 高约 0.6%。`NB=192` 两次成绩相差 16.48 GFLOP/s，而两种配置的均值只相差 0.91 GFLOP/s。五组的第二轮成绩均低于第一轮，说明同组复跑的波动需要纳入判断。

## HPCG 结果

单位为 GFLOP/s。6 次运行的最终校验均为 `VALID`。

| 每进程局部网格 | 第一轮 | 第二轮 | 平均 |
|---|---:|---:|---:|
| 32³ | 6.81431 | 7.86911 | 7.34171 |
| 64³ | 3.96281 | 4.79128 | 4.37705 |
| 96³ | 4.65761 | 4.71248 | 4.68505 |

`32³` 在本轮短测中两次都最高。不同网格的全局工作量相差较大，这组结果只反映该机在各网格下的短测评级。CSV 中 `runtime_s` 来自基准报告，`elapsed_s` 是脚本记录的整个进程运行时间。

## 复跑命令

按 [基线构建说明](../README.md) 设置 `HPL_BIN`、`HPCG_BIN` 和本地 OpenBLAS 的库路径。在仓库的 `week1-hpl-hpcg` 目录中运行以下命令。

```bash
export OUT_ROOT="$root/sweep-2026-11-15" LAUNCHER=mpirun THREADS=1
for nb in 128 192 256 320 384 384 320 256 192 128; do
  bash run_hpl.sh 4 2 2 11520 "$nb" </dev/null
done
for n in 32 64 96 96 64 32; do
  bash run_hpcg.sh 4 "$n" "$n" "$n" 30 </dev/null
done
```
