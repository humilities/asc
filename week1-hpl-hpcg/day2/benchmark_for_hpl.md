## 一、 输入/输出参数说明

| **参数**   | **含义说明**                                 |
| ---------- | -------------------------------------------- |
| **T/V**    | 挂钟时间 / 编码变体                          |
| **N**      | 系数矩阵 $A$ 的阶数                          |
| **NB**     | 分块因子的划分大小                           |
| **P**      | 进程行数                                     |
| **Q**      | 进程列数                                     |
| **Time**   | 求解线性系统所花费的时间（秒）               |
| **Gflops** | 求解线性系统的执行速率（每秒十亿次浮点运算） |
